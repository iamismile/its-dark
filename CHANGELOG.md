# Change Log

All notable changes to the "Its Dark" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Refined professional dark color palette (slate/navy foundation)
- Signature accent color for improved visual hierarchy
- Expanded syntax token coverage for TypeScript, JavaScript, HTML, CSS, Python, Java, C#, Markdown, JSON, YAML
- Professional marketing README with feature showcase and previews
- MIT License

### Changed
- Replaced neon accent colors with a cohesive, production-ready palette
- Improved contrast ratios for better readability
- Unified UI colors (activity bar, sidebar, tabs, status bar, terminal)

### Removed
- Distracting competing accent colors

## [9.0.0] - 2026-11-19

### Changed
- Major theme overhaul: professional dark palette and refined syntax colors
- Updated extension metadata and marketplace assets

## [8.0.1] - 2026-11-19

### Changed
- Minor color refinements and sample image updates

## [8.0.0] - 2026-11-19

### Added
- Initial public release of Its Dark theme
